## 🌟 Tổng Quan Dự Án (Project Overview)

**EdClub Typing Jungle** là một ứng dụng web giáo dục cao cấp, tái hiện và mở rộng chương trình học gõ phím chuẩn quốc tế **Typing Jungle (Program 3)** của EdClub/TypingClub, kết hợp hệ sinh thái trò chơi hóa (gamification) hấp dẫn và kho tri thức tin học văn phòng thực chiến.

Ứng dụng được thiết kế tối ưu cho học sinh, sinh viên và người đi làm với giao diện hiện đại, trực quan, hỗ trợ song ngữ toàn diện (**Tiếng Việt & English**), hoạt động mượt mà không cần cài đặt.

---

## 🚀 Tính Năng Nổi Bật (Key Features)

### 1. ⌨️ Hệ Thống Luyện Gõ Chuẩn EdClub (Typing Jungle)
- **Hơn 100+ Bài học phân cấp từ Cơ bản đến Chuyên sâu**:
  - Hàng phím cơ sở (*Home Row - F, J, D, K, S, L, A, ;*)
  - Hàng phím trên (*Top Row - E, I, R, U, T, Y, W, O, Q, P*)
  - Hàng phím dưới (*Bottom Row - V, M, B, N, C, ,, X, ., Z, /*)
  - Phím số & Ký tự đặc biệt (*Numbers & Symbols - 1-0, !, @, #, $, %, ^, &, \*, (, )*)
  - Gõ hoa & Phím Shift (*Capitalization & Shift Key Mastery*)
  - Bài tập tốc độ, đoạn văn văn bản thực tế & đo lường kỹ năng nâng cao.
- **Bàn phím ảo & Hướng dẫn ngón tay (Virtual Keyboard & Finger Guide)**:
  - Hiển thị trực quan vị trí 10 ngón tay với mã màu chuẩn hóa từng ngón.
  - Phản hồi vị trí bấm phím theo thời gian thực (Real-time active key feedback).
- **Công cụ đo lường thời gian thực (Live Analytics Engine)**:
  - Đo chính xác Tốc độ gõ (**WPM** - Words Per Minute) và Độ chính xác (**Accuracy %**).
  - Ghi nhận chi tiết phím gõ sai và thời gian hoàn thành.
  - Xếp hạng sao (1 - 5 Sao) dựa trên chỉ số đạt được so với mục tiêu bài học.

### 2. 🎵 Động Cơ Âm Thanh Web Audio (Sound FX Engine)
- Hệ thống tổng hợp âm thanh bằng **Web Audio API** không phụ thuộc file mp3 bên ngoài:
  - Chủ đề phím cơ (**Mechanical Switch** - Blue/Brown switch clicky).
  - Chủ đề gõ êm (**Soft / Typewriter**).
  - Âm thanh phản hồi lỗi gõ nhẹ nhàng, không gây ức chế.
  - Hiệu ứng âm thanh khi hoàn thành bài tập và chiến thắng màn chơi.
  - Chế độ tắt tiếng (Mute) chỉ với 1 click.

### 3. ⚔️ Đấu Trường Quái Vật (Monster PK Typing Battle RPG)
- Chế độ game nhập vai chiến đấu với quái vật bằng kỹ năng gõ phím nhanh.
- Hệ thống thanh máu Boss (HP bar), đếm chuỗi liên hoàn (Combo Streak), sát thương chí mạng (Critical Strike).
- Càng gõ nhanh và chuẩn xác, đòn tấn công càng uy lực để tiêu diệt Boss trong thời gian quy định.

### 4. 🏎️ Đua Xe Nhập Dữ Liệu Tốc Độ (Data Entry Speed Run)
- Trò chơi đua xe kịch tính: Gõ nhanh các định dạng số liệu kế toán, tiền tệ, mã đơn hàng và công thức Excel để kích hoạt bình Nitro $N_2O$ bứt phá về đích.

### 5. 📊 Cẩm Nang & Trình Giả Lập Excel/Word (Office Pro Hub)
- **Công thức Excel từ Cơ bản đến Chuyên sâu**:
  - Các hàm kinh điển: `SUM`, `AVERAGE`, `COUNT`, `IF`, `VLOOKUP`, `INDEX/MATCH`.
  - Các hàm thế hệ mới: `XLOOKUP`, `UNIQUE`, `FILTER`, `TEXTJOIN`, `SUMIFS`, `COUNTIFS`.
  - **Trình giả lập công thức tương tác (Interactive Formula Playground)**: Cho phép nhập giá trị và xem kết quả tính toán tức thì.
- **Phím tắt & Mẹo văn phòng đỉnh cao (Pro Hacks & Shortcuts)**:
  - Flash Fill (`Ctrl + E`), Tạo bảng thần tốc (`Ctrl + T`), Chèn ngày giờ (`Ctrl + ;`), Dán giá trị (`Ctrl + Alt + V`), v.v.
  - Tính năng tìm kiếm phím tắt nhanh và sao chép công thức 1-click.

### 6. 🏆 Phòng Vinh Danh & Chứng Chỉ (Trophy Room & Certificates)
- Huy hiệu thành tích mở khóa tự động (Speed Demon, Accuracy Master, Streak Legend, v.v.).
- Chứng nhận hoàn thành khóa học (Certificate of Completion) cá nhân hóa với tên học viên, cấp độ WPM và mã xác thực có thể tải/in.

### 7. 🌐 Đa Ngôn Ngữ Song Ngữ (Bilingual i18n Support)
- Chuyển đổi mượt mà giữa **Tiếng Việt** và **English** trên toàn bộ ứng dụng.
- Dữ liệu dịch thuật được cấu trúc chuẩn hóa theo schema chặt chẽ.

## 🛠️ Công Nghệ Sử Dụng (Tech Stack)

| Thành phần | Công nghệ |
| :--- | :--- |
| **Giao diện & Framework** | React 18 (TypeScript), Vite |
| **Tạo kiểu (Styling)** | Tailwind CSS (Design System chuẩn mực, hỗ trợ tương phản cao) |
| **Biểu tượng (Icons)** | Lucide React |
| **Xử lý âm thanh (Audio)** | Web Audio API (Sine/Square synthesizer, Polyphonic click engine) |
| **Đồ họa & Hiệu ứng (Game/Graphics)**| HTML5 Canvas 2D & RequestAnimationFrame loop |
| **Lưu trữ dữ liệu (Persistence)** | Browser LocalStorage (Tự động lưu tiến độ, lịch sử bài tập, điểm số) |
| **Đa ngôn ngữ (i18n)** | Custom React Context Provider + Type-safe JSON/TS dictionaries |

## ⚡ Hướng Dẫn Cài Đặt & Chạy Cục Bộ (Getting Started)

### Yêu cầu môi trường
- Node.js version 18.0 trở lên.
- npm hoặc yarn hoặc bun/pnpm.

### 1. Cài đặt các gói phụ thuộc (Dependencies)
```bash
npm install
```

### 2. Khởi chạy máy chủ phát triển (Development Server)
```bash
npm run dev
```
Mở trình duyệt tại địa chỉ: `http://localhost:3000`

### 3. Kiểm tra lỗi mã nguồn (Linting)
```bash
npm run lint
```

### 4. Đóng gói cho môi trường thực tế (Production Build)
```bash
npm run build
```

## 📜 Quy Tắc & Mẹo Luyện Gõ 10 Ngón Hiệu Quả
1. **Tư thế ngồi chuẩn**: Lưng thẳng, mắt nhìn thẳng màn hình, cổ tay nâng nhẹ không tì ép mạnh lên bàn.
2. **Vị trí phím cơ sở (Home Row)**:
   - Tay trái: Ngón út đặt ở phím `A`, ngón áp út ở `S`, ngón giữa ở `D`, ngón trỏ ở `F`.
   - Tay phải: Ngón trỏ đặt ở `J`, ngón giữa ở `K`, ngón áp út ở `L`, ngón út ở `;`.
   - Hai ngón cái phụ trách phím cách (**Spacebar**).
3. **Quy tắc vàng**: **Ưu tiên Độ chính xác trước, Tốc độ sẽ tự động tăng sau!** Tránh nhìn xuống bàn phím khi gõ (*Touch Typing*).
