# Generated UFO background themes

Generated with the built-in image_gen tool. Final project assets are WebP files in `public/ufo/background-{sunset,cosmic,forest}.webp`.
These images form the scenic layer behind the transparent schoolyard. Camera-aligned trees and doors remain in the sprite layer.
The game randomly selects a new theme on entry and each launch, excluding the current theme. Failed loads keep the previous theme.
Images are loaded on demand and browser-cached; there is no per-frame image generation or backdrop painting.
